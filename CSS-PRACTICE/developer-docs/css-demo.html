Z-Index Bug

An element with a higher z-index can still appear behind another element when stacking contexts are involved.

=====

What happened?

----- has z-index: 9999, but its parent creates a stacking context. The parent is placed below =====, so the child cannot escape that stacking context.

Specificity Bug

A class selector cannot override a more specific ID selector.

What happened?

The ID selector has higher specificity than the class selector, so the class cannot override it.

Fix the conflict without using !important.
